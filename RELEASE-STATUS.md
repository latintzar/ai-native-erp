## Extraction decisions

- Cedar’s release build keeps English/Spanish source transforms and emits truthful export/upstream provenance. The original multi-project publisher and owner deployment jobs stay with their original environment.
- Actual private operator phones/email become reserved synthetic fixture identities. The fictional 68-SKU catalogue remains. Founder grants, sender addresses and outbound account identifiers require explicit installation configuration.
- Optional support uses an installation-owned VITE_SUPPORT_WIDGET_URL, with GitHub issues as its empty/default path. The original support account is not loaded. Copilot model evidence accepts the configured model identifier.
- Legacy browser identity bootstrap reads the installation’s explicitly public IdP identifiers and excludes privileged/secret keys. Provider keys stay in selected private files; `doctor` prints names/status.
- Existing initials Avatar replaces only the unlicensed Meta reference photograph. Product paintings, component design, typography, map/units/document systems and provider adapters retain their source.
- Compatible Vite/DOMPurify updates, removal of unused Android CLI tooling and a CJS-compatible `uuid` override for ExcelJS clear the recorded npm audit findings. Excel/PDF and the retained frontend suite cover the affected export path.
