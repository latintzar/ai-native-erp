# WhatsApp app-choice icons

These provider icons belong to Cedar's connection setup and keep their provider appearance
independent of the Rocoto theme.

- [WhatsApp Business](whatsapp-business.webp) comes from [Peter's supplied Google Play image](https://play-lh.googleusercontent.com/4LJ6f3U5wANt09KBlZ-F-YKooCQXTwHsa3vtTBFmsXWmNy-AdBEoHnWmyT0mGxh-1pQetlSoc9mIkRDJotQYbg=w512-rw),
  retrieved on 2026-09-09 using the CDN's 512px WebP rendition. The UI rounds the app icon's corners.
- [WhatsApp glyph](whatsapp-glyph.png) is an unchanged copy of Rocoto's existing
  [transparent WhatsApp asset](../../../../assets/whatsapp-logo-green.png).
  [Peter's supplied PNGTree image](https://png.pngtree.com/png-vector/20221018/ourmid/pngtree-whatsapp-mobile-software-icon-png-image_6315991.png)
  returned a Cloudflare challenge during retrieval on 2026-09-09. The existing glyph
  provides the fallback. CSS renders its glyph white on Peter's exact `#27d365` background;
  the source pixels remain unchanged.

The app-store links beside each choice open the corresponding provider listing. The choice
buttons independently start the account connection or the phone-app transfer instructions.
