# Rocoto website

The open-source product website uses the original Rocoto brand, catalogue illustrations and real workspace captures.

Run from the repository root:

~~~sh
python3 -m http.server 8081 --bind 127.0.0.1 --directory website
~~~

Open http://127.0.0.1:8081. The page links the food-distributor app, repository and guides. Edit its product links for your own deployment. Inter and Fraunces retain the OFL texts in assets; product artwork retains the repository’s illustration notices.
